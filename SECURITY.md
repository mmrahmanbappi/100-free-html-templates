# Security Policy

These templates are static HTML, CSS and JavaScript with no server code. They don't collect or store data unless you connect a form service yourself.

## Reporting a problem

If you find a security issue, such as a script that could be abused or an unsafe link, please report it privately. Use [GitHub private vulnerability reporting](../../security/advisories/new) instead of opening a public issue.

You'll get a reply within 7 days.

## Using the templates safely

- The contact forms point to a placeholder Formspree address. Replace it with your own form service before you publish.
- Remove the black "Free HTML template" notice bar at the top of each page before you publish.
- Only load scripts from sources you trust.
