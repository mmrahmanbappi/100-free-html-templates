# Free HTML Website Templates

Free website templates, each in a single HTML file. Download one, change the text and photos, and your website is ready to upload. No WordPress, no page builder, no monthly fees.

**[See every template with a live demo](https://mmrahmanbappi.github.io/free-html-templates/)** &nbsp;|&nbsp; **[Download all as ZIP](https://github.com/mmrahmanbappi/free-html-templates/archive/refs/heads/main.zip)**

## Why use these templates

- **One file each.** The CSS and JavaScript are inside the HTML file, so there is nothing to install or build.
- **Works on phones.** Every template adjusts to phones, tablets and desktops.
- **SEO ready.** Page titles, meta descriptions, social sharing tags and schema markup are already set up.
- **Real example text.** Written like a real business, not lorem ipsum, so you can see how your site will read.
- **Free for business use.** MIT license. Use them for your own site or for clients.

## How to use a template

1. Open a template folder and download `index.html`, or download the whole collection as a ZIP.
2. Open the file in a text editor such as VS Code or Notepad++.
3. Change the text, colours and photos. Colours are listed at the top of the `<style>` block.
4. Upload the file to GitHub Pages, Netlify, Cloudflare Pages or your own web host.

## Questions

**Are these HTML templates really free?**<br>Yes. Every template is free for personal and commercial use under the MIT license. You don't need to sign up, pay or add a credit link.

**Do I need to know coding to use them?**<br>No. Basic editing is enough. Open the index.html file in a text editor such as VS Code or Notepad, change the words, phone numbers and image links, then save the file.

**How do I put a template online for free?**<br>Upload the index.html file to GitHub Pages, Netlify or Cloudflare Pages. All three have free plans and take about ten minutes to set up.

**Can I use a template for a client's website?**<br>Yes. The MIT license lets you use, change and sell websites built with these templates, including work you do for clients.

**Are the templates good for SEO?**<br>Yes. Each template has a page title and description, social sharing tags, schema markup, alt text on every image and a clear heading order, so Google can read and rank the page.

**Will the templates work on mobile phones?**<br>Yes. Every template adjusts to phones, tablets and desktop screens, and has been checked at common screen sizes.
