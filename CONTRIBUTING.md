# Contributing

Thanks for helping improve Free HTML Templates.

## Ways to help

- **Report a bug.** Something looks broken on a phone, a button doesn't work, or a photo doesn't load. [Open a bug report](../../issues/new?template=bug_report.yml).
- **Ask for a template.** Tell us what kind of website you need. [Request a template](../../issues/new?template=template_request.yml).
- **Fix something yourself.** Pull requests are welcome.

## Rules for every template

- One self-contained `index.html` file per template. No frameworks and no build step.
- Works on phones (test at 375 px wide) and on desktop.
- Accessible: one `<h1>`, labels on form fields, alt text on images, visible focus styles.
- Photos from Unsplash only, with no brand logos.
- Plain, friendly English. No em dashes.
- Title 62 characters or fewer, meta description 160 or fewer.

## Making a pull request

1. Fork the repo and create a branch.
2. Make your change and check it in a browser at phone and desktop sizes.
3. Open a pull request and fill in the checklist.

By contributing, you agree your work is released under the [MIT License](LICENSE).
